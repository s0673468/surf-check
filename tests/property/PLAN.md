# Surf Property/Fuzz Plan

Surf is a no-build static JavaScript app, so the property suite uses deterministic seeded generators under `node:test` instead of adding a dependency. CI runs 80 reproducible examples; the local deep profile runs 1000 examples.

| Module or format | Logic owned | Invariants | Format/corruption contract | Coverage |
| --- | --- | --- | --- | --- |
| `surf-config.js` | Beach/profile data, score weights, text dictionaries | Config values stay finite where scoring expects numbers; generated samples are anchored to real beach definitions | Static JavaScript, no on-disk data format owned | `score-model properties preserve score bounds and determinism` |
| `runtime-utils.js` | Numeric parsing, compass/distance/date helpers | `numericCell` is total over hostile cells and returns only `null` or finite numbers; compass output is deterministic; clamp consumers keep score values bounded | Static JavaScript, no on-disk data format owned | `numeric helpers are total over hostile cells` |
| `forecast-api.js` | Open-Meteo payload validation and hourly field normalization | Missing optional hourly arrays are filled with `null`; invalid payloads fail with explicit `Error`; valid normalized payloads do not crash downstream selectors | Network JSON payloads are fixture-generated only; no network in tests | `hourly payload normalization is total for generated API shapes` |
| `score-model.js` | Score, score parts, labels, and reasons | Generated normalized samples produce deterministic byte-identical score objects; score is an integer 0..100; parts/details are finite where numeric; prose reasons do not leak `NaN`/`undefined` | Static JavaScript, no on-disk data format owned | `score-model properties preserve score bounds and determinism` |
| `forecast-selectors.js` | Forecast view assembly, ranked beaches, sample extraction, tide state | Generated forecast cells are normalized before scoring; missing/short arrays skip or return `null`; ranked beaches stay descending; scored sample cache is deterministic | Browser API JSON is synthetic; no real forecast data is read | `forecast selectors tolerate generated hostile hourly cells` |
| `forecast-prose.js` | Day and spot prose helpers | Reads generated from scored samples are deterministic and never contain `NaN`/`undefined`; language state is part of the cache key | Static JavaScript, no on-disk data format owned | Smoke suite plus selector/score properties |
| `rain-radar.js` | RainViewer metadata normalization, frame matching, tile URLs | Frame normalization is order-invariant after sorting; invalid frames are skipped; selected frame is within tolerance; tile URLs are empty or syntactically complete | Network JSON payloads are fixture-generated only; no network in tests | `radar metadata normalization is sorted and skip-safe` |
| `app.js` | DOM rendering, orchestration, map markers | Thin DOM orchestration; logic is covered through exported selectors, score/prose helpers, and existing smoke/mutation tests | Browser state only; no app-owned on-disk format | Waived here: DOM-heavy rendering is smoke-tested in `tests/smoke.mjs` |
| `index.html`, `styles.css`, assets | Static page shell and media | Script order matches runtime loader; syntax/static privacy checks stay in smoke suite | Static assets, no parse/serialize/state logic | Existing smoke tests |
| `calibration/forecast-truth-ledger.json` | Manual forecast-vs-observation calibration ledger | Valid ledgers analyze deterministically; template/example rows are ignored; malformed entries fail before becoming comparisons | JSON corruption coverage: truncation, dropped/duplicated/reordered lines, flipped byte, empty file, NUL bytes, BOM, CRLF, and one malformed middle record | `forecast truth ledger analysis is deterministic over generated entries`; `forecast truth ledger corruption is caught or rejected cleanly` |
| `scripts/forecast-truth.mjs` | Ledger loading, validation, comparison, markdown summary | Round-trip through JSON keeps analysis stable; summaries are deterministic and escape table pipes; invalid schemas fail with explicit `Error` | Reads only synthetic temp JSON files in corruption tests | Ledger property and corruption tests |

## On-Disk Formats

Surf owns one mutable data format: `calibration/forecast-truth-ledger.json`. Runtime JavaScript and HTML/CSS are static source files covered by syntax/smoke tests rather than corruption mutation.
